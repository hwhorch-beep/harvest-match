How to use Harvest Match

A ten-minute, one-time setup. Then it's just paste and go.

← Back to the app

What you'll need

Harvest Match runs entirely in your browser. There's no account on our side — no sign-up, no password. Instead, you'll create your own Anthropic account and paste your own API key into the app. Your key stays on this device.

1. Make an Anthropic account

Go to console.anthropic.com and sign up. It's free to create the account; you'll add a few dollars of credit in the next step.

2. Add a little credit

Once you're signed in, open Plans & Billing in the sidebar and add $5. This will last you many, many weeks of farmers-market queries — each query costs about 1–3 cents. (Most of the cost is the model doing 3–5 web searches to find the actual recipe links.)

3. Generate an API key

In the Anthropic console, go to API Keys in the sidebar and click Create Key. Give it any name you like (e.g. "harvest match on my phone"). Copy the key it shows you — it starts with sk-ant- and you'll only see it once.

4. Paste it into Harvest Match

Back on the main page, paste the key into the "Anthropic API key" field. Check Remember on this device if you want it to stick around between visits.

5. Paste this week's produce list

Copy the list from Six River Farm's email (or any farm's email, or just type a list yourself). Hit Find recipes. The first run takes 20–40 seconds while the model searches the curated cooking sites for real recipe links.

Where your key lives

Your API key is stored only in this browser's localStorage, on this device. It is sent only to api.anthropic.com — never logged on our side, never included in error messages, never sent to any other server. If you clear your browser data, the key goes away. If you want to revoke it, do so from the Anthropic console at any time.

What it costs

Each query runs Claude Sonnet 4.6 with up to 5 web searches. Typical cost is in the 1–3 cent range. A $5 top-up will last hundreds of queries. Your usage and remaining balance live in the Anthropic console under Usage.

If something breaks

  • "Your API key was rejected" — re-paste it. The key must start with sk-ant-.
  • "Rate-limited" — wait a minute and try again. New Anthropic accounts have low initial limits that lift quickly.
  • "Network error" — check your connection. The app needs to reach api.anthropic.com.
  • Output looks thin — try a more specific list, or include more fleeting items. The model works best when there's a clear "what's the star of the week" question to answer.
